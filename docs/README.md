# 문서 관리

| 폴더            | 목적                             |
| --------------- | -------------------------------- |
| `product/`      | 사용자 흐름, MVP 범위, 화면 명세 |
| `architecture/` | 프론트엔드 구조와 기술 의사결정  |

| `research/`     | 경쟁사, 접근성, 성능 리서치      |
| `conventions/`  | Git, 코드, 포맷팅 컨벤션         |

제품 요구사항이 바뀌면 연관된 화면, API, 검증 기준을 함께 갱신합니다.
