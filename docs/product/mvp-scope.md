# AI Pantry MVP 범위

## 핵심 경험

구매 이력 → 팬트리 후보 → 사용자 상태 확인 → 레시피 추천 → 부족 재료 장바구니 → 주문 수령 → 다음 팬트리 후보의 순환을 만든다.

## 인증 범위

| 항목        | MVP 정책                                                                   |
| ----------- | -------------------------------------------------------------------------- |
| 지원 로그인 | 카카오, 네이버 소셜 로그인                                                 |
| 제외 범위   | 자체 이메일 회원가입·로그인, 비밀번호 재설정, 이메일 인증                  |
| 첫 로그인   | 서비스 이용에 필요한 최소 온보딩을 거쳐 가입 상태를 완성한다.              |
| 계정 식별   | `provider`(`KAKAO` 또는 `NAVER`)와 제공자별 사용자 식별자를 기준으로 한다. |

동일한 사람이 두 제공자로 로그인했을 때 계정을 자동으로 통합하지 않는다. 계정 연결·통합 정책은 고도화 항목으로 별도 합의한다.

## 팬트리 상태

| 상태             | 의미                            | 처리                         |
| ---------------- | ------------------------------- | ---------------------------- |
| `AVAILABLE`      | 사용자가 보유 중이라고 확인     | 레시피 보유 재료로 반영      |
| `UNAVAILABLE`    | 소진했거나 보유하지 않음        | 부족 재료·구매 후보로 반영   |
| `CHECK_REQUIRED` | 수령 또는 조리 후 상태가 불확실 | 홈·팬트리·알림에서 확인 요청 |

MVP에서 정확한 잔여 수량을 추정하거나 자동 차감하지 않는다. 레시피 조리 후 사용 재료는 `CHECK_REQUIRED`로 전환한다.

## 핵심 화면

| 우선순위 | 화면                       | 목적                                               |
| -------- | -------------------------- | -------------------------------------------------- |
| MVP      | 홈                         | 조리 가능 레시피, 부족 재료 레시피, 확인 요청 제안 |
| MVP      | 팬트리                     | 구매 이력 후보와 상태 관리                         |
| MVP      | 레시피 목록·상세           | 보유·부족 재료 확인과 장바구니 연결                |
| MVP      | 장바구니·주문 완료         | 레시피 맥락 유지와 주문 상품의 팬트리 후보 연결    |
| 고도화 1 | 자주 구매한 상품·알림 설정 | 재구매와 식재료 활용                               |
| 고도화 2 | 그룹 관리                  | 동거인과 팬트리·장바구니 공유                      |
